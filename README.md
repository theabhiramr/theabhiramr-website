## How to run:

Requires Node `^20.19.0` or `>=22.12.0` (see `.nvmrc`).

1. Clone the repo
   ```bash
   git clone https://github.com/theabhiramr/theabhiramr.git/
   ```
2. Install dependencies
   ```bash
   cd theabhiramr && npm install
   ```
3. Run locally
   ```bash
   npm run dev
   ```
